# Quote conditions use authenticated technical observations and preserve billing timing

Delegated 2026-10-18 under [hub ADR0025](https://github.com/policy-as-versioned-flux/policy-as-versioned-flux/blob/9340c4c377890fb59364b0513710deb5525b1152/docs/adr/0025-the-assistant-decides-architecture-and-records-it.md), recorded before implementation. [Ticket14 Answer3](https://github.com/policy-as-versioned-flux/policy-as-versioned-flux/blob/9340c4c377890fb59364b0513710deb5525b1152/.scratch/ecosystem/issues/14-insurance-and-the-insurer-party.md) defines signed void/uplift consequences; [ticket37](https://github.com/policy-as-versioned-flux/policy-as-versioned-flux/blob/9340c4c377890fb59364b0513710deb5525b1152/.scratch/ecosystem/issues/37-insurance-round-2.md) leaves their assessment open. Annual aggregate attachment/limit remains chosen; optional sublimits are not added.

Use the existing genuinely scheduled adopter lane, selected by a closed immutable descriptor and independently authenticated through the platform's strict original/run/source/append/signature reader. The descriptor cannot admit itself. The versioned served-policy-conditions/v1 model joins exact quote, exposure, parent, catalogue-source/control, served policy/version and served subject identities; it uses an explicit examined UTC instant and the existing 48h bound. A nonempty complete pass matrix is technically met, an authentic applicable fail is breached, and missing/skipped/incomplete evidence is unobserved. Counted implementation claims and aggregate OSCAL satisfaction cannot supply fulfillment. This assessment concerns the declared served subjects, never legal payability, actual transferred loss or a whole organization's compliance.

Honor the insurer's [signed driftwood terms](https://github.com/policy-as-versioned-insurer/insurer/blob/ff40f72d6cf2169926bdbd0ec9f84ea796745b11/terms/driftwood.yaml), which place uplift at the next re-quote. A technical breach computes the exact signed increment in an explicitly modeled conditional/TCoR view; the contract premium stays unchanged until ordinary signed re-quote and adoption. Void makes modeled retention fully retained without inventing a loss amount. Unknown evidence earns no transfer credit or assumed zero uplift. This preserves both ticket14's computation and the signed contract's timing, rather than silently turning an observation into a bill. [ADR0020/21](https://github.com/policy-as-versioned-flux/policy-as-versioned-flux/tree/9340c4c377890fb59364b0513710deb5525b1152/docs/adr) retain missing-instrument and perspective/currency boundaries; ADR0026 retains source/id keys.

The authenticated source header's governed namespaces bound this technical profile. Probe, reference and infrastructure observations outside that scope cannot fill a required served-subject cell or create an insured breach. An unexplained observed workload within the governed set keeps the matrix incomplete. This scope follows the declared insured subjects, not an arbitrary exclusion list.
